# Реализация алгоритма Эрли (Earley Parser)

Этот проект содержит реализацию синтаксического анализатора для контекстно-свободных грамматик (КС-грамматик) на основе **алгоритма Эрли**.

Алгоритм является универсальным: он позволяет парсить **любые** КС-грамматики, включая:
*   Неоднозначные грамматики.
*   Грамматики с левой рекурсией.
*   Грамматики с $\epsilon$-правилами (пустыми производствами).

Временная сложность алгоритма в худшем случае составляет $O(n^3)$ (для неоднозначных грамматик), для однозначных — $O(n^2)$, а для некоторых классов — $O(n)$.

## Структура проекта

Проект разделен на модули в соответствии с принципами единственной ответственности:

*   **`algo.py`** — Ядро алгоритма. Содержит классы:
    *   `Grammar`: Структура данных для хранения правил.
    *   `EarleyParser`: Основной класс алгоритма. Реализует операции *Predict*, *Scan* и *Complete*.
    *   `EarleyItem`: Вспомогательный класс для представления ситуаций (Items) с точкой.
    *   *Этот файл не содержит кода ввода-вывода и работает с объектами.*
*   **`main.py`** — Точка входа для запуска через консоль. Реализует чтение из `stdin` и вывод в `stdout` согласно формату задания.
*   **`tests.py`** — Набор Unit-тестов. Демонстрирует задание грамматики через исходный код и проверяет сложные случаи (рекурсия, пустота, циклы).

## Инструкция по сборке и требования

Проект реализован на **Python 3**.
Специальная сборка (компиляция) не требуется. Используются только стандартные библиотеки Python.

**Требования:**
*   Python версии 3.7 или выше.

## Запуск кода (Режим тестирования преподавателем)

Для запуска программы, которая считывает грамматику и слова из стандартного ввода, используйте `main.py`.

### 1. Интерактивный ввод / Ввод из файла
```bash
python3 main.py
```

Или, если у вас есть файл с тестом (например, `input.txt`):
```bash
python3 main.py < input.txt
```

### Формат входных данных

Входные данные должны соответствовать спецификации:

1. 3 числа: |N| |Σ| |P| (количество нетерминалов, терминалов, правил).
2. Строка с нетерминалами (например, `S A B`).
3. Строка с терминалами (например, `a b c`).
4. `P` строк с правилами вида `Left -> Right`.
5. Стартовый нетерминал.
6. Число `m` (количество слов для проверки).
7. `m` строк со словами.

## Запуск автоматизированных тестов

Для проверки корректности алгоритма реализованы Unit-тесты. Они задают грамматику программным способом (без парсинга текста), что позволяет изолированно протестировать логику алгоритма.

Чтобы запустить тесты с подробным выводом, выполните команду:

```bash
python3 tests.py
```

Тесты проверяют:

* Классические примеры из учебников.
* Палиндромы, скобочные последовательности, арифметику.
* Граничные случаи: пустые языки, циклические правила, удаление $\epsilon$-правил и длинных правил.
